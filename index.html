Advanced — relay server
The relay sees encrypted blobs, a random topic, your IP and timing. Self-host ntfy for full control.
Honest security model.
  • Messages are AES-256-GCM encrypted. Every event is signed with a per-device ECDSA P-256 key.
  • The relay sees your IP, timing, ciphertext sizes and topic — never plaintext, never your device key.
  • Not forward-secret. If the room code leaks later and someone recorded ciphertext, they can read past messages.
  • Not anonymous. The relay sees your network address.
  • Trust-on-first-use. The first key seen for a device ID is trusted. Verify the room fingerprint out-of-band.
  • Local history is opt-in and encrypted at rest with a key derived from the room code.
  • Browsers cannot guarantee forensic erasure. Clearing deletes Veil's records; recovery may still be possible.
